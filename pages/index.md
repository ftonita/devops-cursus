# DevOps Cursus — материалы

Полные тексты курса: мануалы, квизы для самопроверки, глоссарий и роадмап.
Короткие **интерактивные презентации** по каждой теме — на
[главной странице курса](https://ftonita.github.io/devops-cursus/#toc).

- [Роадмап курса](ROADMAP.md) — порядок тем и их статус.
- [Глоссарий](glossary/GLOSSARY.md) — термины из всех мануалов со ссылками
  на место, где они разобраны.
- Мануалы и квизы — в меню слева, раздел «Manuals».

Сайт собирается и публикуется автоматически пайплайном
[`.github/workflows/pages.yml`](https://github.com/ftonita/devops-cursus/blob/main/.github/workflows/pages.yml)
при каждом изменении ветки `main`. Он же служит живым примером к урокам
[02 — CI/CD](manuals/02-cicd-manual.md) и
[05 — Git-workflow для команд](manuals/05-git-workflow-manual.md).
